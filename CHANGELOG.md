## [0.1.0] - 2026-09-04

### Added

- Standalone Python implementation of the frozen GitNext v1 facts and decision contracts.
- Read-only GitHub REST and GraphQL clients, Python SDK, and `gitnext` CLI.
- Frozen 23-case human-approved Golden corpus with 2,300 deterministic replays.
- Python-only normalization parity, evidence-integrity, packaging, and security gates.
