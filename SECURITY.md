# Security policy

## Supported versions

Security fixes are applied to the latest release line. Version 0.1.x supports Python 3.10 through 3.14.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for `chengcuiping/gitnext` when available. If that channel is unavailable, contact the maintainer through the address published in the package metadata. Do not disclose an unpatched vulnerability in a public issue.

Include the affected version, impact, reproduction steps, and any suggested mitigation. Do not include live credentials, private repository content, or personal data.

GitNext accepts only read operations against GitHub. Any path that permits a write request, leaks a credential, executes analyzed repository code, or silently weakens evidence validation should be treated as a security issue.
